## Description

Cobblemon Smartphone (UNOFFICIAL) is a community Fabric backport of RapidMesck's Cobblemon Smartphone for Minecraft 1.20.1 and Cobblemon 1.5.2.

The phone brings several Cobblemon and world utilities into one item, including Pokémon healing and PC access, Pokédex information and scanning, GPS and structure tracking, and social tools. Optional integrations add access to supported storage and companion mods when those mods are installed.

This port adapts the upstream 1.21.1 code to the Minecraft 1.20.1 and Cobblemon 1.5.2 APIs. The Pokédex scanner uses server-persisted tracking data and server-validated scan requests.

### Requirements

- Minecraft Java Edition 1.20.1
- Fabric Loader 0.16.5 or newer
- Fabric API
- Cobblemon 1.5.2 for Minecraft 1.20.1

### Installation

Install Fabric Loader, Fabric API, Cobblemon 1.5.2, and this mod in the same client or server mods folder. Optional integrations only apply when their corresponding mods are installed.
